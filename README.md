​🌐 English Documentation
​✨ Key Features (v1.2)
​🤖 Multi-Account Manager & Instant Switcher: Save unlimited SIP accounts (Office, Personal, Trunk) with custom labels. Switch between accounts in one tap or manage them effortlessly.
​📡 Live Network Telemetry HUD:
​Connection Type: Real-time detection of 📶 Wi-Fi, 📡 Mobile Data, or 🔌 Ethernet.
​Public IP & ISP Info: Automatically fetches and displays your live Public IP and ISP Name (ISP: ...) with a one-tap refresh button.
​Live Server Ping: Continuously measures and displays latency (⚡ XX ms) to your active SIP server.
​🎨 Luminous AI Cyber-Glass UI: Bright electric-teal and lavender-violet glassmorphic interface with a circular dialpad (ABC, DEF sub-letters), haptic feedback, and a dynamic Call / End Call toggle button.
​🔔 Incoming Call Ringtone & Vibration: Plays your device's default ringtone with vibration patterns on incoming SIP calls.
​📊 Tabbed Call History Table: Organized call logs separated into All, Missed ❌, Dialed 📤, and Received 📥 tabs in a clean tabular view—tap any row to redial immediately.
​⏺️ Built-In Call Recording & Player: Records calls in crystal-clear .wav format (Music/SIP_Recordings/) with an integrated in-app audio player (🎧 Recs).
​📈 Post-Call Quality Analytics: Displays a detailed summary card showing MOS Score (1.0 – 5.0), Packet Loss (%), Jitter (ms), Latency (ms), and Audio Codec.
​🇧🇩 বাংলা ডকুমেন্টেশন (Bengali)
​✨ অ্যাপের মূল বৈশিষ্ট্যসমূহ (সংস্করণ ১.২)
​🤖 মাল্টি-অ্যাকাউন্ট অ্যাড ও ইনস্ট্যান্ট সুইচিং: অফিস, পার্সোনাল বা ট্রাঙ্ক—যত খুশি SIP অ্যাকাউন্ট আলাদা নাম (Label) দিয়ে সেভ করে রাখুন এবং টপ বারে ট্যাপ করে মুহূর্তেই এক অ্যাকাউন্ট থেকে অন্য অ্যাকাউন্টে সুইচ করুন।
​📡 লাইভ নেটওয়ার্ক, IP ও ISP মনিটর:
​নেটওয়ার্ক মোড: বর্তমানে ফোনে 📶 Wi-Fi নাকি 📡 Mobile Data চলছে তা রিয়েল-টাইমে দেখাবে।
​পাবলিক IP ও ISP: আপনার বর্তমান পাবলিক আইপি এবং ইন্টারনেট সেবাদাতার নাম (ISP: ...) স্বয়ংক্রিয়ভাবে দেখাবে।
​লাইভ সার্ভার পিং: অ্যাক্টিভ SIP সার্ভারের সাথে প্রতি ৩ সেকেন্ড পরপর লাইভ পিং (⚡ XX ms) দেখাবে।
​🎨 উজ্জ্বল AI গ্লাসমরফিক UI: দিনের আলোতেও স্পষ্ট ও আকর্ষণীয় ইলেকট্রিক ব্লু-ভায়োলেট গ্লাস ডিজাইন, ABC/DEF সাব-লেটারযুক্ত ডায়ালপ্যাড এবং মাঝখানে ডায়নামিক Call / End Call বাটন।
​🔔 ইনকামিং কল রিংটোন ও ভাইব্রেশন: কল আসলে ফোনের রিংটোন বাজবে ও ভাইব্রেট হবে।
​📊 ট্যাব ও টেবিল আকারে কল হিস্ট্রি: All, Missed ❌, Dialed 📤, এবং Received 📥—এই ৪টি আলাদা ট্যাবে ও পরিপাটি টেবিল আকারে কল লিস্ট দেখুন এবং যেকোনো সারিতে ট্যাপ করে সরাসরি কল করুন।
​⏺️ কল রেকর্ডিং ও ইন-অ্যাপ প্লেয়ার: কল চলাকালীন এক ট্যাপেই .wav ফরম্যাটে কল রেকর্ড করুন (Music/SIP_Recordings/ ফোল্ডারে সেভ হবে) এবং অ্যাপের ভেতর থেকেই প্লে করে শুনুন।
​📈 কল কোয়ালিটি রিপোর্ট: কল শেষে MOS স্কোর, Packet Loss, Jitter, Latency এবং Audio Codec-এর বিস্তারিত রিপোর্ট দেখুন।
